    Scan & scrape assist

    When a scrape can't find a confident TMDb match, ask AI to suggest a cleaner title from the filename and retry the lookup. Nothing is changed automatically — you review and apply each suggestion yourself.

    Needs review

      Reorganize media

      Scan a media root and propose consistent folder names and file locations (subtitles included) so both the scanner and you can read your library easily. Nothing changes until you review and approve the plan — SWARM only ever renames/moves files here, never deletes.

      What is MCP?

      MCP lets an AI assistant — Claude, Codex, or any other MCP-compatible client — look things up in your library on your behalf. It's read-only: it can search and check status, but it can't change settings or touch your files.

      Try asking

      Once connected, just ask in plain language — no special syntax needed:

      Claude / Codex
      You: What comedies are in my library?
      AI: I found 18 comedies. A few highlights are Game Night, Palm Springs, and Clue.

      MCP Server

      Create a token, enable the server, save, and restart SWARM. Your AI tool sends this token with each MCP request so only clients you configure can access your library.

      Connect an AI tool

      Add this Streamable HTTP server to your AI tool's MCP configuration. Replace the LAN IP, keep the bearer token private, then restart the AI tool.

      How to organise your media folders
      
      
        
      SWARM scans one or more media roots — folders you point it at from the Details tab. When you add a root you also pick its asset type (Movies, TV shows, Music, or Mixed) so SWARM knows what to expect there. A root can't overlap another root, and you can run with more than one.
      
        
      Inside a root, follow the same layout Plex, Jellyfin, and Kodi use:
      
        
        
          
      • Movies — Movie Name (Year)/Movie Name (Year).mkv. Extras go in Featurettes/, Trailers/, Deleted Scenes/, etc. beside the movie.
        • 
          
      • TV — Show Name (Year)/Season 01/Show Name - S01E02.mkv. Multi-episode files (S01E02-E03) and a Specials/ season are recognised.
        • 
          
      • Music — Artist/Album/01 Track Title.flac. Disc folders (CD1/) are absorbed automatically.
        • 
          
      • Subtitles — a .srt/.vtt next to the video (optionally in a Subs/ folder), named after it, e.g. Movie Name (Year).en.srt.
        • 
        
      
        
      A "Mixed" root can contain top-level Movies/, TV/, and Music/ folders and SWARM will sort them out. The Media roots info button on the Details tab repeats this with more detail.
      
      
      
    
      

    
      
      Want the technical details?
      
      
        
      Every connection between your devices is end-to-end encrypted with TLS 1.3 — the same standard banks use — and mutually verified, so a device has to be one you've actually invited before it can ever connect.
      
        
      New devices join with a short one-time code you generate yourself. On your home network, a device can also be trusted directly with its own short-lived pairing code — nothing has to leave your network to do it.
      
        
      Signing in to generate codes needs a basic account (just an email and password) that's kept completely separate from your media — it stores nothing about your library, your files, or what you watch. Login credentials on your devices are kept in hardware-backed secure storage, not as plain files anything could read.
